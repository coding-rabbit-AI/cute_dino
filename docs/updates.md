## 2026년 10월 9일 — 클라이언트 모드 안내

클라이언트 모드와 각 모드의 주요 기능을 안내합니다.

### 시스템 · 라이브러리

- **Cloth Config API** — 모드의 인게임 설정 화면(GUI)을 제공합니다.
- **Forge Config API Port** — Forge용 모드 설정을 Fabric에서 사용할 수 있도록 호환을 돕습니다.
- **Architectury API** — REI 등 여러 모드가 사용하는 기반 라이브러리입니다.

### 요리 · 농사 확장

- **Rustic Delight** — 팬케이크, 커피, 피망, 면화 등 작물과 요리를 추가합니다.
- **More Delight** — 다양한 음식과 요리 도구를 추가합니다.
- **Crate Delight** — 음식과 작물을 보관할 수 있는 상자를 추가합니다.
- **Delightful** — 여러 요리 모드의 아이템과 레시피를 통합합니다.

### 편의성 · 플레이

- **REI (Roughly Enough Items)** — 아이템 목록과 조합법을 확인할 수 있습니다.
- **Inventory Sorter** — 인벤토리와 상자의 아이템을 자동 정렬합니다.
- **Traveler's Backpack** — 액체 탱크, 작업대, 침대 기능이 있는 배낭을 추가합니다.
- **AppleSkin** — 허기·포만감과 음식 회복량을 표시합니다.
