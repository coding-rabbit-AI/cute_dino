# 명령어 모음

채팅창에서 `/`를 누르면 사용할 수 있는 명령어를 볼 수 있습니다.

## 기본 명령어

| 명령어 | 설명 |
| --- | --- |
| `/help` | 사용 가능한 명령어 확인 |
| `/list` | 접속 중인 플레이어 목록 |
| `/seed` | 월드 시드 확인 (서버 설정에 따라 제한) |
| `/msg 닉네임 내용` | 귓속말 |

## 이동 · 홈

| 명령어 | 설명 |
| --- | --- |
| `/sethome` | 현재 위치를 홈으로 설정 |
| `/home` | 홈으로 이동 |
| `/tpa 닉네임` | 해당 플레이어에게 이동 요청 |

::: tip
서버에 설치된 모드에 따라 사용 가능한 명령어가 다릅니다. 안 되는 명령어는 관리자에게 문의하세요.
:::
