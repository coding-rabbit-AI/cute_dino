# 생존 기본 가이드

처음 접속했다면 아래 순서대로 시작해 보세요.

## 첫날 체크리스트

- [ ] 나무를 모아 작업대와 나무 도구를 만든다
- [ ] 돌 도구로 업그레이드한다
- [ ] 침대를 만든다 (리스폰 지점 설정과 밤 건너뛰기)
- [ ] 임시 쉼터를 짓는다
- [ ] 음식을 확보한다 (동물 사냥이나 밀 농사)

## 자원 모으기

- 철은 지하 깊은 곳에서 많이 나옵니다. 횃불을 넉넉히 챙기세요.
- 다이아몬드는 아주 깊은 층에서 주로 발견됩니다.
- 광질 전에 물과 용암 위치를 먼저 확인하세요.

## 안전 수칙

- 동굴에서는 양동이에 물을 담아 가면 낙사나 용암 사고에 도움이 됩니다.
- 죽으면 아이템이 떨어지므로 사망 위치를 꼭 기억하세요. 좌표는 `F3` 키로 볼 수 있습니다.
- 먼 곳으로 떠나기 전에 [홈을 설정](/guide/protection)해 두세요.
