# 명령어

채팅창에서 명령어를 입력합니다. `/help`는 현재 서버에서 사용할 수 있는 명령어를 보여 줍니다. 서버 설정과 권한에 따라 일부 명령어는 동작하지 않을 수 있습니다.

## 플레이어

| 명령어 | 설명 |
| --- | --- |
| `/help` | 사용 가능한 명령어 보기 |
| `/list` | 접속 중인 플레이어 보기 |
| `/msg 닉네임 내용` | 플레이어에게 귓속말 보내기 |
| `/tell 닉네임 내용` | 귓속말 보내기 (`/msg`와 같은 용도) |
| `/r 내용` | 마지막 귓속말에 답장하기 |
| `/invsort sort` | 내 인벤토리 정렬 (Inventory Sorting 모드 설치 시) |

## 이동

Waystones 모드가 설치되어 있으면 월드에 놓인 웨이스톤을 이용해 활성화한 장소 사이를 이동할 수 있습니다. `/home`이나 `/tpa`는 별도 모드나 플러그인이 있어야 하므로, 서버에서 제공되는지 `/help`로 확인하세요.

## 관리자 전용

아래 명령어는 권한이 있는 운영자만 사용할 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/seed` | 월드 시드 확인 |
| `/time set day` | 시간을 낮으로 변경 |
| `/weather clear` | 날씨를 맑게 변경 |
| `/gamemode survival 닉네임` | 플레이어 게임 모드 변경 |
