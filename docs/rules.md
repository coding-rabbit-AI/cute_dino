# 서버 규칙

모두가 즐겁게 플레이하기 위한 최소한의 약속입니다.

## 기본 규칙

1. **타인의 건축물과 영역을 침범하거나 훼손하지 않습니다.** 허락 없이 부수거나 가져가는 행위는 금지입니다.
2. **버그나 오류를 악용하지 않습니다.** 발견하면 관리자에게 알려 주세요.
3. **비방과 괴롭힘을 하지 않습니다.** 채팅에서도 서로 존중해 주세요.
4. **서버에 과도한 부하를 주지 않습니다.** 대형 레드스톤 장치, 대규모 농장, 엔티티 대량 생성은 만들기 전에 관리자와 상의해 주세요.

## 건축 · 자원

- 건축 전에 근처에 다른 사람의 건축물이 있는지 확인합니다.
- 공용 시설(스폰, 상점 등)은 개인 용도로 변경하지 않습니다.
- 자원 지대는 다 쓴 뒤 최소한 정리해 주세요.

## 제재

규칙을 어기면 경고, 일시 정지, 영구 차단 순으로 조치될 수 있습니다. 심한 경우에는 경고 없이 바로 차단합니다.

::: tip 문의
규칙에 대한 질문이나 신고는 관리자에게 직접 전달해 주세요.
:::
