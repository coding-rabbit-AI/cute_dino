# 서버 접속 방법

## 서버 정보

| 항목 | 내용 |
| --- | --- |
| 서버 주소 | `서버주소를_여기에_입력` |
| 게임 버전 | Java Edition `1.20.x` (정확한 버전은 관리자에게 확인) |
| 모드 로더 | Fabric |

::: warning 주소 입력 필요
이 페이지의 서버 주소는 자리표시자입니다. `docs/connect.md`에서 실제 주소(터널링 주소 등)로 바꿔 주세요.
:::

## 접속 순서

1. 마인크래프트 런처에서 서버 버전과 같은 버전으로 실행합니다. 모드가 필요하면 [모드 · 리소스팩](/guide/mods)을 먼저 확인하세요.
2. 멀티플레이 메뉴에서 **서버 추가**를 누릅니다.
3. 서버 주소에 위 주소를 붙여 넣고 저장합니다.
4. 서버를 선택해 접속합니다.

## 접속이 안 될 때

- 게임 버전과 서버 버전이 같은지 확인하세요.
- 서버가 켜져 있는지 관리자에게 물어보세요. 개인 서버라 항상 켜져 있지 않을 수 있습니다.
- 화이트리스트를 쓰는 서버라면 닉네임이 등록되어 있어야 합니다.

더 많은 해결 방법은 [FAQ](/faq)를 참고하세요.
