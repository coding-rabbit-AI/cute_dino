# 영역 보호 · 홈 · 텔레포트

::: warning 서버 설정에 따라 다릅니다
아래 명령어는 서버에 해당 모드나 플러그인이 설치되어 있어야 동작합니다. 실제 사용 가능한 기능에 맞게 이 문서를 수정해 주세요.
:::

## 영역 보호

내 건축물을 다른 플레이어로부터 지키는 기능입니다. 보호 영역 안에서는 허락받지 않은 사람이 블록을 부수거나 상자를 열 수 없습니다.

- 건축을 시작하기 전에 영역을 먼저 설정하세요.
- 함께 쓰는 친구는 영역 멤버로 추가할 수 있습니다.

## 홈과 텔레포트

| 하고 싶은 일 | 명령어 예시 |
| --- | --- |
| 홈 설정 | `/sethome` |
| 홈으로 이동 | `/home` |
| 친구에게 텔레포트 요청 | `/tpa 닉네임` |

## 추천 습관

1. 기지를 지으면 바로 홈을 설정합니다.
2. 멀리 탐험하기 전에 현재 좌표를 메모합니다.
3. 친구 건축물에 들어갈 때는 허락을 구합니다.
