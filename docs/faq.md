# 자주 묻는 질문

## 서버에 접속이 안 돼요

게임 버전이 서버와 같은지, 서버 주소에 오타가 없는지 확인하세요. 그래도 안 되면 서버가 꺼져 있을 수 있으니 관리자에게 문의해 주세요.

## "모드가 다릅니다" 같은 오류가 떠요

클라이언트에 필요한 모드가 설치되지 않았거나 버전이 다른 경우입니다. [모드 · 리소스팩](/guide/mods) 페이지를 확인하세요.

## 건축물이 부서졌어요

[영역 보호](/guide/protection)를 설정하지 않았다면 복구가 어려울 수 있습니다. 관리자에게 상황을 알려 주세요.

## 서버가 갑자기 끊겨요

개인 서버라 점검이나 재시작이 있을 수 있습니다. 잠시 후 다시 접속해 보세요.

## 위키 내용을 고치고 싶어요

각 페이지 하단의 **이 페이지 수정 제안하기**를 누르면 GitHub에서 바로 수정할 수 있습니다.
