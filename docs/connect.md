# 서버 접속

## 서버 정보

| 항목 | 내용 |
| --- | --- |
| 에디션 | Java Edition |
| Minecraft 버전 | 1.20.x — 정확한 버전은 접속 전에 운영자에게 확인 |
| 모드 로더 | Fabric |
| 서버 주소 | 운영자가 공유한 주소를 입력하세요 |
| 화이트리스트 | 사용 여부와 등록은 운영자에게 확인하세요 |

> 서버 주소와 정확한 게임 버전은 공개 문서에 아직 입력되지 않았습니다. 운영자가 공유한 정보를 사용하세요.

## 접속 순서

1. Minecraft와 Fabric Loader를 서버와 같은 버전으로 설치합니다.
2. [모드 목록](/guide/mods)을 보고 필요한 클라이언트 모드를 설치합니다.
3. 런처에서 Fabric 프로필을 실행합니다.
4. 멀티플레이에서 서버 주소를 입력하고 접속합니다.

## 접속이 안 될 때

- Minecraft 패치 버전과 Fabric Loader 버전이 서버와 같은지 확인합니다.
- 서버가 켜져 있는지, 화이트리스트 등록이 필요한지 운영자에게 확인합니다.
- 필수 클라이언트 모드가 빠지지 않았는지 [모드 목록](/guide/mods)을 확인합니다.

문제가 계속되면 오류 화면이나 로그와 함께 운영자에게 알려 주세요.
