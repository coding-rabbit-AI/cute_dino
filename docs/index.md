## 접속 방법

Fabric Loader 설치부터 서버 접속까지의 [자세한 안내](/connect)를 확인하세요.

## 서버 규칙

- 우리 모두 배려와 존중하는 마음을 가집시다.
- 상자 정리를 꾸준히 합시다.
- 서버를 터트리지 맙시다.
- 치트를 남용하지 맙시다.
